# Demo security lecture notes

This file is synthetic demo data for the homework app, not a course lecture.

## Authentication

Passkeys use public key cryptography. The private key stays with the user's device, and the credential is bound to the website's domain. This helps passkeys resist phishing because a fake site cannot obtain a valid authentication signature for the real site's domain.

## Authorization

Least privilege means giving an account only the access required for its task. Review permissions as roles change and remove access that is no longer needed.

## Incident response

An incident response plan should identify who investigates alerts, how evidence is preserved, and how affected users are notified.
