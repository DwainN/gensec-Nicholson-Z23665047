Security Advisory: CVE-2021-44228 (Log4Shell)

Apache Log4j2 2.0-beta9 through 2.15.0 lets an attacker run code through JNDI lookups in log messages. The CVSS v3 base score is 10.0 (Critical).

Affected hosts found in this scan: 10.0.0.12, 10.0.0.31.

Reference: https://nvd.nist.gov/vuln/detail/CVE-2021-44228

Fix: upgrade to Log4j 2.17.1 or later.
